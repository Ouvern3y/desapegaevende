# Guia de Imagens — Chaveirinhos de Natal

Coloque as imagens reais nesta pasta (`assets/`) com os nomes abaixo para que a landing page as exiba automaticamente:

| Arquivo | Seção | Observações |
| --- | --- | --- |
| `mockup-hero.png` | Seção 01 (Primeira Dobra) | **PNG com fundo transparente** (`object-fit: contain`, sem fundo sólido). |
| `identificacao-presentes.jpg` | Seção 02 (Identificação) | Foto relacionada a presentes e lembrancinhas natalinas. |
| `solucao-produto.png` | Seção 03 (Solução) | Imagens do produto ilustrando a praticidade dos modelos prontos. |
| `apresentacao-20-modelos.png` | Seção 04 (Apresentação) | Visão geral dos 20 modelos natalinos. |
| `apresentacao-personalizacao.png` | Seção 04 (Apresentação) | Exemplo destacando espaço para fotos, nomes e mensagens. |
| `apresentacao-folha-a4.png` | Seção 04 (Apresentação) | Folha A4 com os modelos organizados. |
| `apresentacao-exemplos.png` | Seção 04 (Apresentação) | Exemplos de chaveirinhos personalizados prontos. |
| `prova-social-1.png` ... `4.png` | Seção 05 (Provas Sociais) | Prints reais de conversas (configuráveis em `config.js`). |
| `mockup-oferta.png` | Seção 06 (Card da Oferta) | **PNG com fundo transparente** (`object-fit: contain`). |
| `mariana-alves.jpg` | Seção 08 (Representante) | Foto de Mariana Alves (~30 anos, cabelo castanho, luz natural, ambiente natalino discreto). |
| `encerramento-chaveirinhos.jpg` | Seção 10 (Encerramento) | Imagem bonita dos chaveirinhos personalizados. |
